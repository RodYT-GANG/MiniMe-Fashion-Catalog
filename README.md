# Mini Me Fashion Catalog

Public, image-only clothing texture catalog for Mini Me - Face 3D. This repository distributes user-authored PNG fabric sheets. It does not receive face scans, face photographs, biometric geometry, camera frames, or device identifiers.

## UV bases

- `upper-base-v1`: ANNY-derived torso and sleeve shell used by T-shirt, hoodie, jacket, and puffer presets.
- `lower-base-v1`: ANNY-derived pelvis and leg shell used by jeans and sweatpants presets.

See [`CATALOG_AUTHORING.md`](CATALOG_AUTHORING.md) and the PNG UV guides under `catalog/v1/guides/`.

The catalog starts empty. Add only artwork you have permission to publish. Keep the mesh UVs and layout IDs unchanged.
